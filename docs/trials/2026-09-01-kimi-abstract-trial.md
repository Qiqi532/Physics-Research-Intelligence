## 运行中发现并修复的问题

1. 合成测试最初并行发送分类与解读，触发限流。连接测试现改为顺序执行，并有回归测试约束调用顺序。
2. Kimi K3 的解读超过原 45 秒超时，因此首轮真实摘要基线改用 `kimi-k2.6` 和 120 秒超时。
3. Kimi K2.6 的默认思考输出与严格 JSON 契约不稳定。适配器现在对该模型关闭思考模式，使用 `max_completion_tokens`，传入严格 JSON Schema，并在 system Prompt 中明确附上完整结构。
4. 修复后，两项 AI 任务在三篇真实论文上均通过本地 Zod Schema，并成功持久化。
