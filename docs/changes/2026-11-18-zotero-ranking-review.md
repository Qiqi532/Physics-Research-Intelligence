# 阶段 2–3 Zotero 与日报排序回放

## Zotero 附件

`pnpm evidence:zotero --list` 列出本地库的收藏夹。`pnpm evidence:zotero --collection KEY` 读取单个收藏夹。使用库标识、收藏夹键、条目键和附件键记录归属，文件与目录索引共用 SHA-256。主文和补充材料保留各自的文档版本与物理页。

复核收藏夹个体版本和附件列表的库版本后，原子更新附件快照。客户端离线或同步期间版本变化时保留上次成功索引。实测 CFET 与垂直集成收藏夹的两份 PDF 均可复用已有页索引，复扫仍复用两份。附件替换、离线保留与主文或补充材料的跳页由隔离库回归覆盖。[Zotero 本地 API](https://www.zotero.org/support/dev/web_api/v3/local_api)

## 排序与反馈

日报在关键词过滤前采集公开候选，并在同一事务保存生产筛选候选和评估快照。回放近七个不同日报日，排重范围为同一研究画像。现有关键词方案复用生产的预筛逻辑。摘要方案以公开种子训练词频及逆文档频率权重，使用余弦相似度，对同一研究方向中的种子等权计算。混合排序采用 55% 的关键词分数和 45% 的摘要相似度。

试点缓存按 DOI 核对了 5 篇种子的公开摘要。每种方案报告前五的已评、值得精读和未评数，并统计抽查样本中未入前五的正反馈。界面显示真实日报模型尝试数和离线回放的零调用。反馈按论文 ID 保存，支持无 DOI，收藏、阅读状态及笔记独立。已发布日报直接读取原快照。

历史公开期刊语料使用截至各发表日的 30 日窗口。2026-08-04 至 2026-08-27 的七个发表日，共七个窗口，每窗 8–10 篇候选。三种排序均执行成功，每窗覆盖 5 篇种子，模型调用为零。独立试点库的真实日报样本当前为 0/7，真实推荐质量还需要新的日报日期和用户反馈。
