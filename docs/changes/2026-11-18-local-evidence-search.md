# 阶段 0–1 本地证据检索

## 版本保全

`codex/preserve-stage-9b-assets` 指向 `1774aa3`，保存旧 PDF 实现的 7 个提交。`codex/local-evidence-search` 上的 `11394c8` 和 `d002711` 保存 11 月日报源码、迁移、测试及说明。GitHub 集成是后续步骤。

## 使用入口

运行 `pnpm evidence:index --root "文献目录"`，然后在本机打开 `/evidence`。通过 PDF.js 提取文本并渲染物理页，PostgreSQL 全文索引结合中英术语别名。支持逐文件状态、无 DOI 文稿和补充材料。摘录与页码绑定到文件 SHA-256，原件可用时打开对应版本。测试通过了字节去重、文件替换、目录离线、并发锁和旧公开论文清理时保留关联证据。

## 试点方法

本机启动 Docker Desktop 时，Secrets Engine 报告无法访问其 socket。验收使用单独的原生 PostgreSQL 17，索引通过 11 条迁移在独立 schema 创建。

从指定文献目录读取 20 份 PDF。先用 Poppler 独立提取页面，按唯一参考页冻结 20 道查页题，涵盖 10 份 PDF。条件题使用同一行出现的概念和数值，术语题使用原文短语。用 `scripts/run-evidence-evaluation.ts` 输出聚合命中数和查询延迟。题目、摘录和原文件仅保存在本机，版本库记录评测脚本和汇总。

此样本衡量有明确线索的页码查找。双栏顺序与关键数值仍以原页为准，手工阅读耗时须通过实际使用记录。两种提取器的文字顺序和页内空白可能不同。
