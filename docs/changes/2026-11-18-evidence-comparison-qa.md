# 阶段 4–5 器件证据对照表与本地问答

## 器件证据对照表

证据检索卡片和 PDF 原文页都可添加记录。一行对应一组工况，数值与原单位成对保存。界面区分入射功率与功率密度，并为材料、器件结构、偏压、波长、响应度、响应时间和图表号提供独立字段。可留空缺失项，纯图读数以物理页和图表号定位。

Next.js 接口用 Zod 校验输入。Prisma 增量迁移将记录关联到文档内容的 SHA-256 版本，保存物理页和经索引文字核对的摘录。重解析同一文件时，已有记录仍保留当时的摘录。React 页面支持修改和移除记录，以及选中行导出 Markdown 或 UTF-8 CSV。导出带原文页链接。

## 本地证据问答

沿用 PostgreSQL 全文索引查找候选页。在单篇范围内，按术语、指定工况、符号和单位筛选原文。对数值问题要求摘录中有测量量与相应数值。跨篇查证至少需要两篇主文的支持，各篇分别给出摘录和物理页。单篇与跨篇都在环回地址提供，本轮启用确定性的原文摘录，适用于查证明确的测量结果和术语。

双栏页初测有 4 条长引文的行顺序与 Poppler 不一致，每行都能在原页找到。将此类页的引文收窄至仍支持问题的短连续摘录后，重跑了同一批题目。无文字页、纯图读数和缺少共同测量条件的比较仍需查看 PDF。

## 真实试点

- 本机试点库保存了 7 篇已索引论文的 7 条记录，逐条以 SHA-256 对应原件和 Poppler 物理页核对，包含 1 条响应时间、3 条偏压和 3 条波长。选中记录的 Markdown 与 CSV 均通过生产接口下载。该批响应度缺少可独立核对的摘录，列保留空白。
- 相同摘录定位任务中，按已知版本和页码查索引的中位耗时为 4.9 ms，重新提取整份 PDF 再定位该页为 194.9 ms。两者均在原件已读入后计时。该结果衡量查页开销，人工阅读和录入时长未实测。
- 生产端先跑单篇，再跑跨篇。单篇 7/7、跨篇 2/2 道已知有据的问题命中，每种范围各 5/5 道库外或工况不匹配问题得到拒答。17 条返回引文均可由 Poppler 在原 PDF 页复现。样本由本轮真实对照记录构成。
- 同一机器上端到端延迟中位数为单篇 138 ms、跨篇 370 ms，含拒答案例。问答前后预览 Node 进程工作集为 171.7 MiB 和 194.3 MiB，本次观测峰值 195.0 MiB。
- 增量迁移已应用于独立 PostgreSQL 17 试点库。生产预览为 `http://127.0.0.1:3228`，对照表与问答地址分别为 `/evidence/comparison` 和 `/evidence/ask`。
- 7 份试制原件通过预览的 PDF 接口下载并核对 SHA-256。614 项 Vitest、40 项桌面及移动 Playwright 检查、lint、TypeScript 类型检查和生产构建全部通过。
